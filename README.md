# A-Z Solution

A-Z Solution is a modern, responsive, single-page business website designed to provide complete digital solutions for businesses.

The website has a clean premium white design with blue accents and includes services such as web development, graphic design, video editing, digital marketing, and social media management.

---

## ✨ Features

- Premium white and blue UI
- Fully responsive design
- Mobile-friendly navigation
- 3-bar hamburger menu with X animation
- Smooth scrolling
- Active navigation link on scroll
- TextType typing animation
- Hero section with call-to-action buttons
- About section
- Services section
- Work / Portfolio section
- Contact section with form
- Hover animations and transitions
- Clean and minimal layout
- No external frameworks required

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- CSS Animations
- DOM Manipulation
- Media Queries
